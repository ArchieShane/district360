## 内容（相对 0.3.0+6708130）

业务视图（`view_xxx`）从 pop 库迁到 makani_1119 的 `ods_pop_view` schema，本版实现这些视图的抽取与接口：

- **开发建设（ods-dev）**：资本项目（GSEC）、建设许可（EMECS）、竣工 / 维修 / 拆除申请（MEPS）。`dev` 接口新增 `capitalProjects`、`permits`；新地图图层 `projects`。
- **城市运行（ods-ops）**：居民诉求、道路事故、视觉违规、违规处罚（含 UIS）、住宅占用。`ops` 接口新增对应数据块与地块记录 `plotRecords`。
- **市场（ods-mkt）**：Tawtheeq 单元状态（入住率）。`mkt` 接口新增 `occupancy`。
- `overview` 加各项汇总（原字段不变）；`watch` 的延期资本项目、入住率、视觉违规按期整改率三项在有数据后自动可算。
- 各主题接口新增 `sources`（各表行数与原因）。

**源表目前全部为空**：接口返回 0 / 空数组，`sources` 与 `/meta` 的 `note` 为「ODS 源表无数据：…」。数据团队导入后，次日同步自动出数，不用改代码。口径与待核实事项见 [主题库设计 2.7](../District360_V1.0_主题库设计.md) 与 [前端对接文档 7.2 / 7.3 / 7.5 / 7.8](../空间下钻接口_前端对接文档.md)。

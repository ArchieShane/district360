## 内容（相对 v0.2.0）

### 主题库抽取（ods-*，每天 03:00）

- `ods-dev` 开发建设：总规、总规地块、在建工地。
- `ods-mkt` 市场：Tawtheeq 租约（样例）；ADREC 买卖 / 抵押 / 租赁源表到位后自动接入。
- `ods-ops` 城市运行：路灯、公交站。
- `ods-ast` 设施：学校、医疗、药房、清真寺、公园。
- 宜居（v1 liveability 抽取扩展）：CAPEX / OPEX、优先级分档与规则、最缺设施前 3、居民需求前 3，口径与宜居平台 dashboard 一致；发布版本条件补 `status = 'approved'`。

### 接口 `/api/v2/space/nodes/{level}/{key}/…`

`dev`、`mkt`、`ops`、`ast`、`liv`（宜居）、`watch`（需关注区域）、`overview`（首页五主题总览）、`nearby`（地块周边设施）；节点 `stat` 增加建筑面积、可建面积、竣工 / 拆除数；社区 / 地块 `info.masterPlan`。详见 [空间下钻接口_前端对接文档](../空间下钻接口_前端对接文档.md) 6A–6H。

### V1.0 新前端（frontend-360）

部署在 `/district360/v2/`，与 v1 页面并存。按原型实现：首页五主题总览，开发建设 / 市场 / 宜居 / 城市运行 / 设施 / 数据页签，需关注区域（卡片、光晕、连线、脉冲标记），图层菜单（底图、地块着色、设施点位、指标图层），地块 500 / 1000 m 范围圈，楼层上下翻层，中英文切换。与原型的差距见 [原型对比核查](../原型对比核查_20261126.md)。

## 步骤

```bash
cd /tmp && sha256sum -c <<< "<包 SHA-256>  district360-upgrade-0.3.0-<日期>.tar.gz"
mkdir -p /tmp/d360-up && tar xzf district360-upgrade-0.3.0-<日期>.tar.gz -C /tmp/d360-up --no-same-owner
cd /root/district360
S=$(date +%Y%m%d%H%M)
cp -p jar/district360.jar jar/district360.jar.bak-$S && cp -p VERSION VERSION.bak-$S && cp -a static/v2 static.v2.bak-$S
cp /tmp/d360-up/district360/jar/district360.jar jar/district360.jar
cp /tmp/d360-up/district360/VERSION VERSION
find static/v2 -mindepth 1 -delete && cp -R /tmp/d360-up/district360/static/v2/. static/v2/
docker restart district360
```

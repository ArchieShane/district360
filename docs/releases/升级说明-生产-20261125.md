## 起因

排查结论：生产跑的是 11-23 之前的旧 jar（统计库迁移停在 **v8**）。瓦片 `id` 是 `6b7b257`（11-23）才加上的（[StatQueryMapper.xml](../../backend/d360-stat/src/main/resources/mapper/stat/StatQueryMapper.xml) 的 `p.id AS id`）。

## 对接方须知

- 每次 makani 抽取后地块、建筑的 `id` **整体重新生成**（表是整批 `DELETE` + `INSERT`，`id` 为 `bigserial`）。
- 瓦片请求必须带 `?v=`，值取 `GET /meta` 里 makani 的 `lastFinishedAt`；瓦片 `Cache-Control: max-age=3600`，不带 `v` 时最长 1 小时内会拿到过期的 `id`，点击后得到 404。
- nginx / CDN 的缓存键必须包含 query 参数。

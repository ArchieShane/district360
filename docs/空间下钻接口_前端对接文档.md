# District 360 V1.0 · 空间下钻接口 · 前端对接文档（v0.3.0）

> **版本**：v0.3.0（tag `v0.3.0`，2026-11-26 部署到 109）。
> **适用**：按产品原型 V1.0 做「酋长国 → 市政 → 区域 → 社区 → 地块 → 建筑 → 楼层 → 单元」逐级下钻、各主题页签和首页总览的前端。
> **示例**：均取自 109 线上真实返回（2026-11-26），为便于阅读做了截短（`…`）。
> **参考实现**：仓库 `frontend-360/`（Vue 3 + MapLibre），已部署在 `http://10.255.254.109:8360/district360/v2/`；`src/api.ts` 是完整的 TypeScript 类型与请求封装，可直接复用。
> **相关文档**：[接口文档](接口文档.md)（v1 接口与总览）、[原型对比核查](原型对比核查_20261126.md)（与原型的差距）、[ODS 数据缺口清单](ODS数据缺口清单_20261126.md)（缺哪些源数据）。

---

## 0. 快速开始

```bash
B=http://10.255.254.109:8360/district360/api/v2/space
curl "$B/nodes/emirate/AD"                       # 起点：酋长国节点（面板标题、计数、下一级）
curl "$B/nodes/emirate/AD/layers/districts.geojson"   # 地图：全部区域面
curl "$B/nodes/district/ADM-48/overview"         # 区域首页五主题总览
curl "$B/search?q=bateen"                        # 搜索
```

页面状态只有「层级 `level` + 编码 `key`」。拿到任意节点后，用它的 `childLevel` 往下走、用 `path` 往上走、用 `layers` 决定能画哪些图层。

## 1. 基础约定

### 1.1 地址

| 环境 | 接口前缀 | 页面 |
|---|---|---|
| 109 线上 | `http://10.255.254.109:8360/district360/api/v2/space` | 新前端 `…/district360/v2/`；v1 页面 `…/district360/` |
| 本地后端 | `http://localhost:8080/api/v2/space`（端口以启动参数为准） | — |

- **后端没有开启跨域（CORS）**，页面要和接口同源：开发时用开发服务器代理（Vite 示例见 `frontend-360/vite.config.ts`，`/api` 代理到后端），部署时页面放在后端的静态目录下。
- 请求用**相对路径**。参考实现部署在 `/district360/v2/` 下，打包时设 `VITE_API_BASE=../api/v2/space`，即请求 `/district360/api/v2/space/…`；页面挂到别的二级路由时只改这个前缀。
- 全部是 `GET`、只读、不需要鉴权。

### 1.2 统一返回体

```json
{ "code": 0, "message": "ok", "data": { … } }
```

| code | HTTP | 含义 |
|---|---|---|
| `0` | 200 | 成功 |
| `400` | 400 | 参数不对：层级名写错、该层级不支持这个图层、接口不支持这个层级（如在地块上请求 `overview`） |
| `404` | 404 | 编码不存在 |
| `500` | 500 | 服务器内部错误 |

```json
{"code":400,"message":"未知的层级: x（emirate / municipality / district / community / plot / building / floor / unit）","data":null}
{"code":404,"message":"没有这个district: NOPE","data":null}
{"code":400,"message":"首页总览只在酋长国、市政、区域、社区层级提供","data":null}
```

**地图图层接口（`*.geojson`）不包这一层**，直接返回 GeoJSON（`Content-Type: application/geo+json`）。

### 1.3 数据约定

- 坐标：**EPSG:4326 经纬度**，`[经度, 纬度]`。
- 单位：`*Sqm` 平方米、`*Km2` 平方公里、`*Ha` 公顷、`*M` 米、`*Aed` 阿联酋迪拉姆；百分比字段名带 `Pct` / `pct` 或注明 %。
- **值为空的字段不返回**（`info`、列表项里），按「没有该字段 = 空」处理。
- 数值统一按 `number` 处理（可能整数也可能带小数）。
- 日期 `YYYY-MM-DD`；时间戳（如 `loadedAt`）为 UTC ISO 8601。
- 名称：`name` 是英文或编号拼出来的显示名（如 `Plot 4b`、`F2-2`），`nameAr` 只有市政、区域、社区有。
- 接口返回的提示文字（如需关注区域的指标名、阈值、`note`）是中文；参考实现的中英文切换在前端做（`frontend-360/src/i18n.ts`），接口不分语言。

## 2. 层级与编码

| level | 中文 | key 规则 | key 示例 | 下一级 | 可用图层（节点视图 `layers`） |
|---|---|---|---|---|---|
| `emirate` | 酋长国 | 固定 `AD` | `AD` | municipality | `municipalities`、`districts` |
| `municipality` | 市政 | 市政编码 | `ADM` / `AAM` / `WRM` | district | `districts` |
| `district` | 区域 | `<市政>-<区编号>` | `ADM-48` | community | `communities`、`plots`、`buildings`、`masterplans`、`sites`、`busstops`、`streetlights`、`facilities` |
| `community` | 社区 | `<市政>-<区编号>-<社区编号>` | `ADM-1300-710` | plot | `plots`、`buildings`、`masterplans`、`sites`、`busstops`、`streetlights`、`facilities` |
| `plot` | 地块 | GIS ID（gisid） | `10004344286` | building | `buildings`、`sites`、`facilities` |
| `building` | 建筑 | `udm-<内部编号>`；只有 BDMS 分层数据的为 `bdms-<市政>-<编号>` | `udm-9358149` | floor | `floors`、`units` |
| `floor` | 楼层 | `<市政>-<楼层编号>` | `ADM-611142` | unit | `units` |
| `unit` | 单元 | `<市政>-<单元编号>` | `ADM-1227944` | —（最末级） | — |

- 编码是字符串，**不要当数字处理**（gisid 11 位，可能超出数值精度或带前导零）。
- 编码里可能有 `-`，放进 URL 路径时用 `encodeURIComponent`。**不要自己拼编码**，一律用接口返回的 `key`。
- 市政编码：`ADM` 阿布扎比市政、`AAM` 艾因市政、`WRM` 达夫拉地区市政。下钻起点：`emirate / AD`。
- 建议把当前节点记在地址栏（如 `#/building/udm-9358149`），可分享、可前进后退。

## 4. 节点视图 `GET /nodes/{level}/{key}`

### 返回 `data`

| 字段 | 类型 | 说明 |
|---|---|---|
| `level` / `key` | string | 当前节点 |
| `name` / `nameAr` | string / string \| null | 显示名 / 阿拉伯文名（只有市政、区域、社区有） |
| `path` | `{level,key,name}[]` | 上级链，从酋长国开始，**不含自己**；面包屑、层级条直接用。**可能跳级**（建筑对不上地块时没有 plot 这一级） |
| `childLevel` / `childCount` | string \| null / number | 下一级层级和个数（地块不含已注销；单元为 `null` / 0） |
| `bbox` | `[minLon, minLat, maxLon, maxLat]` | 外包框，地图定位用（MapLibre `fitBounds`） |
| `center` | `[lon, lat]` | 面内一点，放标签用 |
| `geometry` | GeoJSON Geometry \| null | 节点自身形状，地图描边高亮用；区域及以上已简化；酋长国为 `null` |
| `info` | object | 本层级属性，**字段随层级不同**，见 4.1 |
| `stat` | object | 计数汇总，见 4.2 |
| `breakdowns` | object | 分组统计，见 4.3 |
| `layers` | string[] | 本节点可请求的地图图层 |

### 4.1 `info` 字段（按层级）

所有下级节点都带全部上级编码：`municipalityCode`、`districtKey`、`communityKey`、`plotKey`、`buildingKey`、`floorKey`（有就返回）。字段中文名见 `frontend-360/src/labels.ts` 的 `INFO_LABEL`。

| 层级 | 字段 |
|---|---|
| municipality | `municipalityId`、`areaKm2` |
| district | `districtId`、`popularNameEn`、`population`、`areaKm2` |
| community | `communityId`、`popularNameEn`、`compositeNameEn`、`areaKm2`、`masterPlan`（所属总规，面积最大的前 3 个，「 / 」连接） |
| plot | `gisid`、`plotId`、`plotNumber`、`elmsPlotId`、`areaSqm`、`plannedAreaSqm`、`constructionStatus`、`serviceStatus`、`planningStatus`、`plotStatus`、`primaryUse`、`parentLandUse`、`landUse`、`secondaryUse`、`ownershipType`、`allocationStatus`、`investmentName`、`devcode`、`devcodeCategory`、`devcodeFar`（允许容积率，**文本**）、`devcodeMaxGfa`（可建面积 m²）、`maxHeights`、`zoneTpss`、`sectorTpss`、`projectId`、`permitLastType`、`permitLastDate`、`cancelDate`、`srcDistrictEn`、`srcCommunityEn`、`modifiedDate`、`masterPlan` |
| building | `source`、`buildingId`、`buildingInternalId`、`bdmsBuildingId`、`gisid`、`physicalStatus`、`primaryUsageType`、`primaryUse`、`secondaryUsageType`、`floorsCount`（登记层数）、`heightM`、`completionDate`、`demolitionDate`、`startDate`、`permitId`、`constructionSiteId`、`isBdms`、`bdmsFloors`、`bdmsUnits`、`footprintSqm` |
| floor | `source`、`floorId`、`bdmsBuildingId`、`floorNumber`、`floorSeq`（自下而上序号）、`baseHeightM`、`floorHeightM`、`areaSqm`、`buildingStatus`、`plotPrimaryUse`、`buildingFloors` |
| unit | `unitId`、`unitNumber`、`unitType`、`usageType`、`classification`、`category`、`areaSqm`、`bedrooms`、`bathrooms`、`balconyAreaSqm`、`floorNumber`、`baseHeightM`、`floorHeightM`、`buildingStatus` |

**`source`（数据来源）**：建筑 `udm` = 现状建筑台账，`bdms` = 台账里没有、由 BDMS 楼层外包面推导；楼层 `bdms_floors` = BDMS 楼层表，`bdms_units` = 由单元推导。推导数据建议加「推导数据」标注。

### 4.2 `stat` 计数

| 字段 | 说明 | 出现层级 |
|---|---|---|
| `municipalities`、`districts` | 市政数、区域数 | emirate（`districts` 也在 municipality） |
| `communities` | 社区数 | emirate ~ district |
| `plots` | 地块数（不含已注销） | emirate ~ community |
| `plotsConstructed` / `plotsUnderConstruction` / `plotsNotConstructed` | 已建 / 在建 / 空置地块数。**建成率 = `plotsConstructed / plots`**，前端算 | 同上 |
| `plotsAreaSqm` | 地块面积合计 | 同上 |
| `buildings` / `buildingsUnderConstruction` | 建筑数 / 在建建筑数 | emirate ~ plot |
| `floors` / `units` | BDMS 楼层数 / 单元数 | emirate ~ building |
| `floorsAreaSqm` | 建筑面积 GFA：楼层面积合计 | emirate ~ building |
| `unitsAreaSqm` | 使用面积：单元面积合计；emirate ~ building **不计**单个 > 10,000 m² 的异常单元 | emirate ~ floor |
| `unitsAreaOutliers` | 被排除的异常单元数 | emirate ~ building |
| `plotsMaxGfaSqm` | 可建面积：未注销地块 `devcodeMaxGfa` 合计。单个地块的**可建面积使用率 = `floorsAreaSqm / info.devcodeMaxGfa`**；区域层级很多地块没登记可建面积，不建议算比率 | emirate ~ plot |
| `buildingsCompleted` / `buildingsDemolished` | 有竣工 / 拆除日期的建筑数（累计；全酋长国约 1,900 / 1 栋，最近 2021-04） | emirate ~ plot |
| `lastCompletionDate` / `lastDemolitionDate` | 最近竣工 / 拆除日期（没有时不返回） | emirate ~ plot |
| `unitsWithBedrooms` / `bedrooms` | 有卧室的单元数 / 卧室总数 | floor |

不适用的字段返回 `0`（如建筑节点的 `plots`）。楼层、单元只覆盖有 BDMS 分层数据的建筑。

### 4.3 `breakdowns` 分组统计

每组是 `[{ k, n, area }]`：取值、个数、面积（m²），按 `n` 降序，最多 24 项。

| 键 | 含义 | 面积口径 | 出现层级 |
|---|---|---|---|
| `plotStatus` | 地块建设状态 `Constructed` / `Under Construction` / `Not Constructed` / `Unknown` | 地块面积 | emirate ~ community |
| `landUse` | 地块主要用途（Residential、Commercial…） | 地块面积 | emirate ~ community |
| `buildingUse` | 建筑主要用途 | **固定为 0**，只看 `n` | emirate ~ plot |
| `buildingStatus` | 建筑状态（existing、As Planned…） | 固定为 0 | plot |
| `unitClass` | 单元户型（Apartment、Villa…） | 单元面积（**含异常单元**，面积只作参考） | emirate ~ floor |
| `unitType` | 单元类型 | 单元面积 | building |
| `bedrooms` | 卧室数（`"0"`、`"1"`…，未知为 `"—"`） | 单元面积 | building、floor |

地块状态的中文与颜色（与原型一致）：`Constructed` 已建 `#3D6DF2`、`Under Construction` 在建 `#F0914A`、`Not Constructed` 空置 `#62D36A`。

## 5. 下一级列表 `GET /nodes/{level}/{key}/children`

| 参数 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `level`、`key` | 路径 | | 父节点 |
| `page` | query | `0` | 页码，从 0 开始 |
| `size` | query | `50` | 每页条数，最大 500 |
| `q` | query | | 关键字，见下表 |

返回 `{ "items": [ … ], "page": 0, "size": 2, "total": 55, "hasMore": true }`。每项都有 `key`、`name`、`sub`（副标题，可能没有），其余字段随下一级不同：

| 下一级 | 字段 | `q` 匹配 | 排序 |
|---|---|---|---|
| municipality | `areaKm2`、`districts`、`communities`、`plots`、`buildings`、`units` | 名称、编码 | 名称 |
| district | `areaKm2`、`population`、`communities`、`plots`、`plotsConstructed`、`buildings`、`units` | 英文名、阿拉伯文名（模糊） | 名称 |
| community | `areaKm2`、`plots`、`plotsConstructed`、`buildings`、`units` | 名称（模糊）、社区编号 | 名称 |
| plot | `areaSqm`、`status`（建设状态）、`use`（用途）、`buildings`、`units` | 地块号（模糊）、gisid、地块编号 | 地块号 |
| building | `status`、`source`、`floorsCount`、`floors`（BDMS 楼层数，> 0 即有分层数据）、`units`、`heightM` | 名称（模糊）、建筑编号 | 单元数、高度降序 |
| floor | `seq`、`baseHeightM`、`floorHeightM`、`areaSqm`、`units` | 楼层号 | 自下而上（`seq`） |
| unit | `type`、`areaSqm`、`bedrooms`、`bathrooms`、`floorKey` | 单元号、户型 | 楼层、单元号 |

```json
// GET /nodes/district/ADM-48/children?size=2
{"items":[
  {"key":"ADM-48-104","name":"ME1","sub":"ME1","areaKm2":0.585,"plots":16,"plotsConstructed":8,"buildings":68,"units":1},
  {"key":"ADM-48-233","name":"ME10","sub":"ME10","areaKm2":1.215,"plots":492,"plotsConstructed":428,"buildings":439,"units":6828}
 ],"page":0,"size":2,"total":55,"hasMore":true}
```

用法：
- 面包屑下拉（切换同级）：请求**上一级**的 children，`size=200`，输入框文字传 `q`，防抖 250 ms。
- 列表页签：`size=50`，`hasMore` 时「加载更多」（`page + 1`）。社区下的地块可能上千块，**不要一次取全部**。
- 楼层上下翻层：请求所在建筑的 children（`size=500`，已按 `seq` 排好），当前楼层的前一项 / 后一项即下一层 / 上一层。
- 社区按建成率排名：请求区域的 children，用 `plotsConstructed / plots` 排序。

## 6. 地图图层 `GET /nodes/{level}/{key}/layers/{layer}.geojson`

返回 GeoJSON `FeatureCollection`（不包 `code / data`），可直接作为 MapLibre GeoJSON 数据源；HTTP 缓存 5 分钟。`layer` 必须在该节点的 `layers` 里，否则 400。

### 6.1 下钻图层

所有要素都有 `key`、`name`、`level`；点击后用 `level` + `key` 下钻。

| layer | 几何 | 其他属性 | 上限 |
|---|---|---|---|
| `municipalities` | 面（已简化） | `cx`、`cy`（标签点） | 10 |
| `districts` | 面（已简化） | `m`（市政编码）、`cx`、`cy`、`plots`、`buildings`、`units`、`built`（建成率 %，可能缺） | 500 |
| `communities` | 面（已简化） | `cx`、`cy`、`plots`、`buildings`、`units`、`built` | 5,000 |
| `plots` | 面 | `s`（建设状态）、`u`（主要用途）、`area`（m²） | 30,000 |
| `buildings` | 面 | `src`（udm / bdms）、`st`（状态）、`u`（用途）、`fd`（是否有 BDMS 分层）、`h`（拉伸高度 m：有登记高度用高度，否则层数 × 3.5，都没有为 6） | 30,000 |
| `floors` | 面 | `seq`、`b`（底标高 m）、`t`（顶标高 m） | 2,000 |
| `units` | 面 | `floor`（楼层 key）、`c`（户型）、`b`、`t` | 20,000 |

`b` / `t` 直接对应 MapLibre `fill-extrusion-base` / `fill-extrusion-height`。要素 `id` 只是本次返回的序号，**不是业务编码**。

### 6.2 主题图层（要素 `level` 不是下钻层级，点击不要跳转）

| layer | 层级 | 几何 | `level` | 其他属性 |
|---|---|---|---|---|
| `masterplans` | 区域、社区 | 面 | `masterplan` | `stage`、`year`、`dev` |
| `sites` | 区域、社区、地块 | 面 | `site` | `b`（在建建筑数）、`area` |
| `busstops` | 区域、社区 | 点（站台） | `busstop` | `code`、`stop` |
| `streetlights` | 区域、社区 | 点 | `streetlight` | `st`（状态）、`n`（灯盏数） |
| `facilities` | 区域、社区、地块 | 点 | `facility` | `c`（school / medical / pharmacy / mosque / park）、`sub` |

### 6.3 体积

`emirate/AD` 的 `districts` 约 0.3 MB；一个社区的 `plots` / `buildings` 几十 KB ~ 1 MB；建筑最多的区域的 `buildings`（约 2 万栋）约 13.5 MB（已 gzip）；一栋 76 层塔楼的 `units` 约 0.3 MB；建筑最多的区域约 3,600 个路灯点（0.8 MB）。区域级的地块、建筑图层较大，建议缩放到一定级别再请求，或下钻到社区再加载。

### 6.4 各层级建议加载（参考实现的做法）

| 当前层级 | 加载 |
|---|---|
| emirate / municipality | 当前节点的 `districts`（按 `built` 着色，`cx` / `cy` 放名称标签） |
| district | `communities` + `plots` + `buildings` |
| community | `plots`（按 `s` 着色）+ `buildings`（3D 拉伸 `h`） |
| plot | 所在社区的 `plots`（背景）+ 本地块的 `buildings` |
| building | 所在地块的 `buildings`（压暗、去掉本楼）+ 本楼 `floors`（半透明）+ `units`（按 `c` 着色） |
| floor / unit | 所在建筑的 `floors` + 本层（所在楼层）的 `units`，选中单元高亮 |

当前节点自身用 `geometry` 描边；上级节点的 `key` 从 `path` 里取。主题图层在对应页签打开时加载（开发建设：`masterplans`、`sites`；城市运行：`busstops`、`streetlights`；设施：`facilities`）。

### 6.5 图层菜单（不需要额外接口）

- 地块着色：建设状态用 `plots` 的 `s`，土地用途用 `u`。
- 设施点位：`facilities` 按 `c` 过滤，公交站用 `busstops`；地块及以下用 7.7 `nearby` 的点位画范围圈。
- 指标图层：酋长国 / 市政的区域面——建成率用 `districts` 的 `built`；宜居分 / 达标投资 / 优先级用 7.4 `liv` 的 `districts[].pipeline / capexAed / tier`，按 `key` 匹配着色。区域内的社区面——建成率用 `communities` 的 `built`。
- 宜居分配色（与原型一致）：≤ 45 红 `#D7303A`、67.5 黄 `#F2D45C`、≥ 90 绿 `#3FB45F`，线性插值；不在评估范围灰 `#5B6270`（`labels.ts` 的 `livColor`）。

### 7.8 需关注区域 `GET /nodes/{level}/{key}/watch`

酋长国、市政。越过任一阈值的区域及越过的每一项；排序为轮流取每项指标里最差的区（同一区只出现一次）。

| 指标 `key` | 名称 | 默认阈值 | 现状 |
|---|---|---|---|
| `gap` | 距目标差距（只看评估范围内） | ≥ 8 分 | 可算 |
| `capex` | 达标所需投资，附占比 | ≥ AED 400M | 可算 |

| `park` | 公园供给率 = 现有 ÷ 需求面积（只看需求 ≥ 5 公顷的区） | < 50% | 可算 |
| `vio` | 视觉违规按期整改率 | < 68% | 不可算（缺源数据） |

「数据」页签和各页签「待接入」状态用。

## 11. 典型交互流程

```
打开页面（#/emirate/AD）
  ├─ GET /nodes/emirate/AD                    → 面板
  ├─ GET /nodes/emirate/AD/overview           → 首页五块
  ├─ GET /nodes/emirate/AD/watch              → 需关注区域卡片
  └─ GET /nodes/emirate/AD/layers/districts   → 地图区域面 + 名称标签
点击地图上的区域（要素 level=district, key=ADM-48）
  ├─ 地址栏改为 #/district/ADM-48
  ├─ GET /nodes/district/ADM-48 + /overview   → 面板、fitBounds(bbox)
  └─ GET …/layers/communities、plots、buildings
切到某个页签 → GET /nodes/district/ADM-48/{dev|mkt|liv|ops|ast}（+ 对应主题图层）
点击社区 → 地块 → 建筑 → 楼层 → 单元（同上；地块及以下设施页签另请求 /nearby）
点击面包屑上的某一级 → 跳到 path 里那一级的 level + key
```

切换节点时**取消上一次还没返回的请求**（`AbortController`），避免旧结果覆盖新结果。
